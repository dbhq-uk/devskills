# gitview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A skill that prints one table of every branch and worktree in a repository, says which branches are finished, and offers to clear them away.

**Architecture:** Five focused Python modules under `skills/gitview/scripts/`. `gitrepo.py` wraps git, `landed.py` decides whether a branch is finished, `forge.py` looks up pull requests, `table.py` renders, and `gitview.py` is the CLI that wires them together. The script is strictly read-only; the delete and push actions are driven from `SKILL.md` so nothing destructive lives in a script that could run unattended.

**Tech Stack:** Python 3.9+ standard library only. No third-party packages. `git`, and optionally `az` or `gh`, from `PATH`.

**Spec:** `docs/superpowers/specs/2026-09-10-gitview-design.md`

## Global Constraints

- Python 3.9 or newer, standard library only. No third-party runtime dependencies.
- Every subprocess call passes an argument list, never `shell=True`.
- The script never writes to the repository under survey. No commits, deletes, pushes, checkouts of existing branches, or index changes in the working tree.
- Temporary worktrees are created detached under `tempfile.mkdtemp()` and removed in a `finally` block, including on exception.
- No em dashes anywhere, in code, comments, docs or commit messages. Use a comma, a full stop, a semicolon or brackets.
- Never hard-wrap prose in markdown. One paragraph is one line.
- Simple technical English: short sentences, plain words, active voice.
- Nothing identifying a client, project, ticket, person, host or IP address goes into this public repository. Test fixtures use invented names.
- Trunk means the repository's main line, discovered at runtime. Never hardcode `main`.

## File Structure

| File | Responsibility |
|---|---|
| `skills/gitview/scripts/gitrepo.py` | Every git subprocess call. Trunk discovery, worktrees, branches, commit counts |
| `skills/gitview/scripts/landed.py` | The two-tier safe-to-delete engine, and nothing else |
| `skills/gitview/scripts/forge.py` | Forge detection from the remote URL, and pull request listing |

"""Builds a throwaway repository exercising every case gitview must get right."""
import os
import subprocess


def _git(repo, *args):
    env = dict(os.environ, GIT_AUTHOR_NAME="T", GIT_AUTHOR_EMAIL="t@e",
               GIT_COMMITTER_NAME="T", GIT_COMMITTER_EMAIL="t@e")
    return subprocess.run(["git", "-C", repo, *args], check=True, env=env,
                          capture_output=True, text=True).stdout


def _write(repo, name, text):
    with open(os.path.join(repo, name), "w", encoding="utf-8") as fh:
        fh.write(text)


def build(root):
    """Create the repository and return its path."""
    origin = os.path.join(root, "origin.git")
    repo = os.path.join(root, "work")
    subprocess.run(["git", "init", "--bare", "-b", "trunk", origin], check=True, capture_output=True)
    subprocess.run(["git", "init", "-b", "trunk", repo], check=True, capture_output=True)
    _git(repo, "config", "user.name", "T")
    _git(repo, "config", "user.email", "t@e")
    _git(repo, "remote", "add", "origin", origin)

    _write(repo, "shared.txt", "one\n")
    _write(repo, "other.txt", "base\n")
    _git(repo, "add", "-A")
    _git(repo, "commit", "-m", "base")
    _git(repo, "push", "-u", "origin", "trunk")
    _git(repo, "remote", "set-head", "origin", "trunk")

    # landed-squash: its content reaches trunk by squash, and trunk then edits
    # the same file. This is the case that defeats reverse-applying a patch.
    _git(repo, "switch", "-c", "landed-squash")
    _write(repo, "shared.txt", "one\ntwo\n")
    _git(repo, "add", "-A")
    _git(repo, "commit", "-m", "add two")
    _git(repo, "switch", "trunk")
    _git(repo, "merge", "--squash", "landed-squash")
    _git(repo, "commit", "-m", "squash: add two")
    _write(repo, "shared.txt", "one\ntwo\nthree\n")
    _git(repo, "add", "-A")
    _git(repo, "commit", "-m", "trunk edits the same file afterwards")
    _git(repo, "push", "origin", "trunk")
    _git(repo, "push", "-u", "origin", "landed-squash")

    # live-work: genuine unlanded content in a file trunk does not touch.
    _git(repo, "switch", "-c", "live-work", "trunk")
    _write(repo, "feature.txt", "new feature\n")
    _git(repo, "add", "-A")
    _git(repo, "commit", "-m", "a feature")
    _git(repo, "push", "-u", "origin", "live-work")

    # conflicting: edits the same line trunk edited, differently.
    _git(repo, "switch", "-c", "conflicting", "trunk")
    _write(repo, "shared.txt", "one\ntwo\nDIFFERENT\n")
    _git(repo, "add", "-A")
    _git(repo, "commit", "-m", "conflicting edit")
    _git(repo, "push", "-u", "origin", "conflicting")

    # no-upstream: never pushed, so its work exists only here.
    _git(repo, "switch", "-c", "no-upstream", "trunk")
    _write(repo, "local.txt", "local only\n")
    _git(repo, "add", "-A")
    _git(repo, "commit", "-m", "local only")

    # trunk-only: identical to trunk, adds nothing.
    _git(repo, "switch", "-c", "trunk-only", "trunk")

    _git(repo, "switch", "trunk")

    # A worktree whose directory name differs from its branch name.
    _git(repo, "worktree", "add", os.path.join(root, "checkout-alpha"), "live-work")
    # A detached worktree, which must not crash anything.
    _git(repo, "worktree", "add", "--detach", os.path.join(root, "checkout-detached"), "trunk")

```python
# skills/gitview/scripts/gitrepo.py
"""Every git subprocess call gitview makes. Nothing here writes to the repository."""
import os
import subprocess
from dataclasses import dataclass


class GitError(RuntimeError):
    pass


def git(args, cwd, check=True):
    """Run git and return stdout stripped. Raises GitError when check and it fails."""
    result = subprocess.run(["git", "-C", cwd, *args], capture_output=True, text=True)
    if check and result.returncode != 0:
        raise GitError(f"git {' '.join(args)} failed: {result.stderr.strip()}")
    return result.stdout.strip()


def is_repo(cwd):
    try:
        return git(["rev-parse", "--is-inside-work-tree"], cwd) == "true"
    except GitError:
        return False


def trunk(cwd):
    """The repository's main line, discovered rather than assumed.

    origin/HEAD is the honest answer where it exists. Falling back to main then
    master covers a repository with no remote, and returning None says plainly
    that nothing else in this table would mean anything.
    """
    head = git(["symbolic-ref", "--quiet", "refs/remotes/origin/HEAD"], cwd, check=False)
    if head:
        return head.split("refs/remotes/origin/", 1)[-1]
    for name in ("main", "master"):
        if git(["rev-parse", "--verify", "--quiet", name], cwd, check=False):
            return name
    return None


def trunk_ref(cwd, name):
    """Prefer the remote-tracking trunk, because a local one can be stale."""
    remote = f"origin/{name}"
    if git(["rev-parse", "--verify", "--quiet", remote], cwd, check=False):
        return remote
    return name


def worktrees(cwd):
    """Map branch name to the basename of the directory holding it."""
    out = git(["worktree", "list", "--porcelain"], cwd)
    found, path = {}, None
    for line in out.splitlines():
        if line.startswith("worktree "):
            path = line.split(" ", 1)[1]
        elif line.startswith("branch ") and path:
            found[line.split("refs/heads/", 1)[-1]] = os.path.basename(path)
    return found


@dataclass
class Branch:
    name: str
    upstream: "str | None"


def branches(cwd):
    out = git(["for-each-ref", "--format=%(refname:short)%09%(upstream:short)",
               "refs/heads/"], cwd)
    result = []
    for line in out.splitlines():
        name, _, upstream = line.partition("\t")
        result.append(Branch(name=name, upstream=upstream or None))
    return result


def count(cwd, spec):
    out = git(["rev-list", "--count", spec], cwd, check=False)
    return int(out) if out.isdigit() else 0


def remote_url(cwd):
    return git(["remote", "get-url", "origin"], cwd, check=False) or None
```

```python
# skills/gitview/scripts/landed.py
"""Decides whether a branch still contributes anything to the trunk.

A branch is finished when merging the trunk into it produces the trunk's tree
exactly. Then it adds nothing, whatever its commit count says.

Read references/safe-to-delete.md before changing any of this. Both of the
obvious cheaper tests are wrong, and the wrongness is silent.
"""
import os
import shutil
import tempfile
from dataclasses import dataclass

import gitrepo


@dataclass
class Verdict:
    state: str
    detail: str


def _tree(cwd, ref):
    return gitrepo.git(["rev-parse", f"{ref}^{{tree}}"], cwd)


def fast_is_landed(cwd, trunk_ref, branch):
    """Tier one: a trivial three-way merge into a temporary index, no checkout.

    Definitive only when it says yes. If every path resolves to the trunk's
    version, the branch either never touched it or agrees with it, which is
    exactly what contributing nothing means.

    A no answer proves nothing, because read-tree refuses any file both sides
    edited, even where a real merge would combine the two edits cleanly.
    """
    base = gitrepo.git(["merge-base", trunk_ref, branch], cwd, check=False)
    if not base:
        return False
    handle, index = tempfile.mkstemp(prefix="gitview-index-")
    os.close(handle)
    os.unlink(index)
    env_before = os.environ.get("GIT_INDEX_FILE")
    os.environ["GIT_INDEX_FILE"] = index
    try:
        if gitrepo.git(["read-tree", "-m", "--aggressive", base, branch, trunk_ref],
                       cwd, check=False) is None:
            return False
        try:
            gitrepo.git(["read-tree", "-m", "--aggressive", base, branch, trunk_ref], cwd)
        except gitrepo.GitError:
            return False
        if gitrepo.git(["ls-files", "-u"], cwd, check=False):
            return False
        return _tree(cwd, trunk_ref) == gitrepo.git(["write-tree"], cwd, check=False)
    finally:
        if env_before is None:
            os.environ.pop("GIT_INDEX_FILE", None)
        else:
            os.environ["GIT_INDEX_FILE"] = env_before
        if os.path.exists(index):
            os.unlink(index)


def _real_merge(cwd, trunk_ref, branch):
    """Tier two: a real merge in a throwaway detached worktree.

    Only reached where tier one could not prove the branch finished. This is
    where conflicts and unlanded are told apart, which tier one cannot do.
    """
    tmp = tempfile.mkdtemp(prefix="gitview-merge-")
    path = os.path.join(tmp, "wt")
    try:
        gitrepo.git(["worktree", "add", "--detach", path, branch], cwd)
        merged = gitrepo.git(["merge", "--no-edit", trunk_ref], path, check=False)
        conflicted = gitrepo.git(["diff", "--name-only", "--diff-filter=U"], path, check=False)
        if conflicted:
            gitrepo.git(["merge", "--abort"], path, check=False)
            names = conflicted.split("\n")
            shown = ", ".join(names[:3]) + (", ..." if len(names) > 3 else "")
            return Verdict("conflicts", shown)
        if merged is None:
            return Verdict("conflicts", "merge refused")
        if _tree(path, "HEAD") == _tree(cwd, trunk_ref):
            return Verdict("landed", "adds nothing to trunk")
        stat = gitrepo.git(["diff", trunk_ref, "HEAD", "--shortstat"], path, check=False)
        return Verdict("unlanded", stat.strip() or "differs from trunk")
    finally:
        gitrepo.git(["worktree", "remove", "--force", path], cwd, check=False)
        shutil.rmtree(tmp, ignore_errors=True)
        gitrepo.git(["worktree", "prune"], cwd, check=False)


def verdict(cwd, trunk_ref, branch):
    """Is this branch finished? Fast path first, real merge only where needed."""
    if fast_is_landed(cwd, trunk_ref, branch):
        return Verdict("landed", "adds nothing to trunk")
    return _real_merge(cwd, trunk_ref, branch)
```

# skills/gitview/scripts/forge.py
"""Finds open pull requests, when the host is one we understand.

This column always degrades rather than fails. A table that refuses to render
because a remote API was unreachable is useless exactly when it is most wanted.
"""
import json
import shutil
import subprocess

_TIMEOUT = 30


def detect(url):
    if not url:
        return None
    lowered = url.lower()
    if "dev.azure.com" in lowered or "visualstudio.com" in lowered:
        return "azure"
    if "github.com" in lowered:
        return "github"
    return None


def parse_azure(raw):
    found = {}
    for item in json.loads(raw or "[]"):
        branch = item.get("sourceRefName", "").replace("refs/heads/", "")
        if branch:
            found[branch] = f"{item.get('pullRequestId')} {item.get('mergeStatus') or ''}".strip()
    return found


def parse_github(raw):
    found = {}
    for item in json.loads(raw or "[]"):
        branch = item.get("headRefName")
        if not branch:
            continue
        state = {"CONFLICTING": "conflicts", "MERGEABLE": "succeeded"}.get(
            item.get("mergeable") or "", "open")
        found[branch] = f"{item.get('number')} {state}"
    return found


def _run(cmd):
    return subprocess.run(cmd, capture_output=True, text=True, timeout=_TIMEOUT)


def list_prs(kind, cwd):
    """Return (branch -> label, reason skipped). One call, never one per branch."""
    if kind is None:
        return {}, None
    tool = {"azure": "az", "github": "gh"}[kind]
    if shutil.which(tool) is None:
        return {}, f"{tool} is not installed"
    if kind == "azure":
        cmd = ["az", "repos", "pr", "list", "--status", "active",
               "--query", "[].{pullRequestId:pullRequestId,sourceRefName:sourceRefName,mergeStatus:mergeStatus}",
               "-o", "json"]
        parse = parse_azure
    else:
        cmd = ["gh", "pr", "list", "--state", "open", "--limit", "200",
               "--json", "number,headRefName,mergeable"]
        parse = parse_github
    try:
        result = _run(cmd if kind == "github" else cmd)
    except (subprocess.TimeoutExpired, OSError) as exc:
        return {}, f"{tool} lookup failed: {exc}"
    if result.returncode != 0:
        first = (result.stderr or "").strip().split("\n")[0][:120]
        return {}, f"{tool} lookup failed: {first or 'non-zero exit'}"
    try:
        return parse(result.stdout), None
    except (ValueError, KeyError) as exc:
        return {}, f"{tool} returned output we could not read: {exc}"
```

# skills/gitview/scripts/table.py
"""Orders the rows and renders the markdown table."""
from dataclasses import dataclass

HEADER = "| Worktree | Branch | PR | Ahead | Behind | Unpushed | Safe to delete |"
RULE = "|---|---|---|---|---|---|---|"


@dataclass
class Row:
    worktree: str
    branch: str
    pr: str
    ahead: int
    behind: int
    unpushed: str
    safe: str


def order(rows):
    """Worktree rows first, then the rest. Worktreeless branches are kept
    deliberately: that is where finished branches hide."""
    return sorted(rows, key=lambda r: (r.worktree == "-", r.worktree, r.branch))


def _cell(value):
    return "**YES**" if value == "YES" else value


def render(rows):
    lines = [HEADER, RULE]
    for row in order(rows):
        lines.append(
            f"| {row.worktree} | `{row.branch}` | {row.pr} | {row.ahead} | "
            f"{row.behind} | {row.unpushed} | {_cell(row.safe)} |"
        )
    return "\n".join(lines)
```

```python
#!/usr/bin/env python3
# skills/gitview/scripts/gitview.py
"""Survey every branch and worktree in a repository.

Read only. It never deletes, pushes, merges or checks anything out. The actions
are driven from SKILL.md so that nothing destructive lives in a script that
could be run unattended.
"""
import argparse
import os
import sys

import forge
import gitrepo
import landed
import table


def survey(cwd, want_prs=True):
    """Return (rows, notes). Notes are things the reader should know."""
    notes = []
    trunk_name = gitrepo.trunk(cwd)
    if trunk_name is None:
        raise gitrepo.GitError("no trunk found: looked for origin/HEAD, main, then master")
    trunk_ref = gitrepo.trunk_ref(cwd, trunk_name)
    notes.append(f"Trunk is `{trunk_ref}`.")

    prs = {}
    if want_prs:
        kind = forge.detect(gitrepo.remote_url(cwd))
        prs, reason = forge.list_prs(kind, cwd)
        if reason:
            notes.append(f"Pull request column skipped: {reason}.")

    checkouts = gitrepo.worktrees(cwd)
    rows = []
    for branch in gitrepo.branches(cwd):
        name = branch.name
        if branch.upstream:
            unpushed = str(gitrepo.count(cwd, f"{branch.upstream}..{name}"))
        else:
            unpushed = "no remote"
        if name == trunk_name:
            safe = "no, trunk"
        else:
            v = landed.verdict(cwd, trunk_ref, name)
            safe = "YES" if v.state == "landed" else f"no, {v.detail}"
        rows.append(table.Row(
            worktree=checkouts.get(name, "-"),
            branch=name,
            pr=prs.get(name, "-"),
            ahead=gitrepo.count(cwd, f"{trunk_ref}..{name}"),
            behind=gitrepo.count(cwd, f"{name}..{trunk_ref}"),
            unpushed=unpushed,
            safe=safe,
        ))
    return rows, notes


def main(argv=None):
    parser = argparse.ArgumentParser(description="Survey branches and worktrees.")
    parser.add_argument("path", nargs="?", default=".", help="repository path")
    parser.add_argument("--verify", metavar="BRANCH",
                        help="exit 0 only if BRANCH is finished. Use before deleting it")
    parser.add_argument("--no-pr", action="store_true", help="skip the pull request lookup")
    args = parser.parse_args(argv)

    cwd = os.path.abspath(args.path)
    if not gitrepo.is_repo(cwd):
        print(f"{cwd} is not a git repository", file=sys.stderr)
        return 2

    try:
        if args.verify:
            trunk_name = gitrepo.trunk(cwd)
            if trunk_name is None:
                print("no trunk found", file=sys.stderr)
                return 2
            if args.verify == trunk_name:
                print(f"{args.verify} is the trunk")
                return 1
            v = landed.verdict(cwd, gitrepo.trunk_ref(cwd, trunk_name), args.verify)
            print(f"{args.verify}: {v.state} ({v.detail})")
            return 0 if v.state == "landed" else 1

        rows, notes = survey(cwd, want_prs=not args.no_pr)
    except gitrepo.GitError as exc:
        print(str(exc), file=sys.stderr)
        return 2

    print(table.render(rows))
    if notes:
        print()
        for note in notes:
            print(note)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

- [ ] **Step 1: Write the reference**

```markdown
# Why "is this branch finished?" is harder than it looks

A branch is finished when merging the trunk into it produces the trunk's tree exactly. Then it contributes nothing, whatever its commit count says.

Two cheaper tests look right and are wrong. Both fail silently, which is what makes them dangerous: they do not error, they just quietly report live work forever, or hide work that matters.

## `git branch --merged` misses every squash merge

Where a repository squashes on merge, the branch's commits never become ancestors of the trunk. A branch whose every line landed weeks ago still never appears as merged. In a repository whose branch policy allows nothing but squash, this test is not merely unreliable, it is always wrong.

## Reverse-applying the branch's patch gives false negatives

Take the branch's diff against its merge base, and try to apply it backwards to the trunk. If it applies cleanly, the content must already be there.

That reasoning is sound and the test still fails, because it depends on context lines. The moment the trunk edits the same files after the branch landed, the surrounding lines no longer match and the patch will not reverse. The content is present. The check says it is missing. The branch looks like live work forever, and nobody deletes it.

This is not hypothetical. It is what sent a survey of one repository badly wrong: two branches were reported as thousands of insertions of unlanded work when in fact both had landed days earlier, and the error was only caught because merging the trunk into one of them produced no change at all.

## The test that works

Merge the trunk into a throwaway copy of the branch, and compare the resulting tree with the trunk's tree. Equal means the branch adds nothing.

gitview does this in two tiers.

**Tier one** is a trivial three-way merge into a temporary index, with no checkout at all: `git read-tree -m --aggressive <merge-base> <branch> <trunk>`, then compare `git write-tree` against the trunk's tree. It runs in milliseconds.

It is definitive only when it says yes. If every path resolved to the trunk's version, then for every path the branch either never touched it or agrees with it, which is what contributing nothing means.

A no answer proves nothing. `read-tree` performs a trivial merge and refuses any file both sides edited, even where a real merge would combine two non-overlapping changes cleanly.

**Tier two** is a real merge in a throwaway detached worktree, run only for branches tier one could not prove finished. It is the only thing that can tell a genuine conflict apart from genuine unlanded work.

## What the columns cannot tell you

Ahead is a commit count against the trunk. A branch merged by squash stays ahead forever. Reading ahead as "unlanded work" is the same mistake in a different form.
```

# gitview - the state of every branch and worktree

One table: worktree, branch, open pull request, ahead, behind, unpushed, and whether the branch is finished.

## Run it

```bash
python3 "$CLAUDE_SKILL_DIR/scripts/gitview.py" [PATH]
```

`PATH` defaults to the current directory. Add `--no-pr` to skip the pull request lookup, which makes it work offline.

Print the table it returns as it comes, then read it for the user. Do not re-sort or re-format it.

## How to read it

- **Ahead** is a commit count against the trunk, not a measure of unlanded work. A branch merged by squash stays ahead forever while contributing nothing.
- **Safe to delete** is the column that answers the question. It is computed by merging the trunk into a throwaway copy of the branch and comparing trees. See [references/safe-to-delete.md](references/safe-to-delete.md).
- **Unpushed** reading `no remote` is the urgent one. That work exists on one machine only.

## What to say

Lead with whatever is at risk of being lost, then what is finished, then what is in flight. Unpushed commits and branches with no remote come first, always.

## Offering the actions

Only after the table has been shown, and only when there is something to offer.

**Branches safe to delete.** Offer to delete them, local and remote together, because a local-only delete leaves the remote to be rediscovered later. Before deleting each one:

1. Re-verify it. A table is a snapshot, and a repository worked by several sessions moves underneath it.

```bash
python3 "$CLAUDE_SKILL_DIR/scripts/gitview.py" --verify BRANCH [PATH]
```

   Exit code 0 means finished. Anything else means do not delete it, and say why.

2. Print the commit SHA first, so the branch can be restored.
3. Refuse any branch that has a worktree or an open pull request, and say so out loud.

**Unpushed work.** Offer to push it. Branches with no upstream need `git push -u origin BRANCH`.

Never merge, complete a pull request, rebase, or resolve a conflict. Those are not this skill's job.

## Requirements

- `git`
- `az` for Azure DevOps pull requests, or `gh` for GitHub. Neither is required: without them the pull request column shows dashes and the reason is printed once.
